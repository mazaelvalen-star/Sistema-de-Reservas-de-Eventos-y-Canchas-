# Trabajo Práctico N.º 2

## Metodología de Sistemas II

**Grupo:** N.º 5

**Proyecto:** Sistema de Reservas del Complejo ATEP.

## Documentación del trabajo práctico

1. Identificación del problema.
2. Solución inicial sin patrón de diseño.
3. Decisión arquitectónica y justificación.
4. Selección del patrón de diseño.
5. Implementación y evidencias.
6. Reflexión sobre el uso de inteligencia artificial.

## Objetivo

Documentar y justificar las decisiones de arquitectura y diseño de software aplicadas al sistema de reservas del Complejo ATEP, relacionando los conceptos teóricos de la materia con su implementación práctica.
